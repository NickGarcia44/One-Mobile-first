# 📱 Projeto Mobile First com Carrossel  

Este é um pequeno projeto desenvolvido com **HTML5 e CSS3 puros**, seguindo a abordagem **Mobile First**, com variações de layout para **celulares, tablets e desktops**.  
Além disso, utiliza a biblioteca **[Swiper.js](https://swiperjs.com/)** para a criação de um carrossel responsivo e moderno.  

---

## 🚀 Tecnologias Utilizadas  
- **HTML5**  
- **CSS3 (responsividade com media queries)**  
- **[Swiper.js](https://swiperjs.com/)**
